IPFS Protocol Support Test

How it works:

This page tests the IPFS protocol support in Chromium.

When you click on an IPFS link, it should be redirected to the local IPFS gateway at http://0.0.0.0:8080

Test Links:

Test IPFS Link
ipfs://QmTWHDsZKruRDBYFKy7CNNR17SLkhWdvhBoiW9YJtsozeT/
This should redirect to: http://0.0.0.0:8080/ipfs/QmTWHDsZKruRDBYFKy7CNNR17SLkhWdvhBoiW9YJtsozeT/ Test IPFS Link with Path
ipfs://QmTWHDsZKruRDBYFKy7CNNR17SLkhWdvhBoiW9YJtsozeT/index.html
This should redirect to: http://0.0.0.0:8080/ipfs/QmTWHDsZKruRDBYFKy7CNNR17SLkhWdvhBoiW9YJtsozeT/index.html

Requirements:

  • IPFS daemon should be running locally on port 8080
  • The gateway should be accessible at http://0.0.0.0:8080
  • Rebuild Chromium with the IPFS protocol support changes
